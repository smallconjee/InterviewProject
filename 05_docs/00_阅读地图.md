# 05_docs 阅读地图（从这份开始）

> 文档太多不用慌：按下面的线走。**A 线是面试冲刺主线**，B 线是系统复习，C 线是日常维护参考。
> 所有面试材料的数字/口径都来自 `面试工具包/00_统一口径与生产数字.md`——改任何数字先改它。
