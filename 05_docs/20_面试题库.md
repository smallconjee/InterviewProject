## 0. 开场与角色定位（每场面试的前 5 分钟，定调区）

- 🔴 请用两分钟介绍一下这个项目。（备 30 秒版 / 2 分钟版两个长度）
  - ↳ 两个项目分别一句话概括是什么？（"海量小文件归档存储+异步云备份" / "结构化文本倒排索引检索"）
- 🔴💣 这个项目是公司真实项目吗？上线了吗？给谁用？
  - ↳ 团队几个人？怎么分工？【口径：团队方案，我负责归档链路（存储+消息可靠性）+ 认证对接】
  - ↳ 你负责归档链路，那报告检索系统也是你做的？两个项目你都有参与？
  - ↳ 项目里哪些是你独立完成的，哪些是跟着团队做的？
- 🔴💣 工作经历写的是"配合完成模块测试、文档维护"，项目却写得非常深，怎么解释？
  - 【口径：岗位职责 vs 项目产出；"配合"讲成"负责模块开发 + 参与联调排查 + 文档是交付的一部分"】
- 📐 生产规模三连：日导入多少影像？单文件多大？存量多少 TB？多少家医院/工作站？
- 📐 部署：几台机器？怎么部署的？配置怎么管理？
- 🔴💣 两个项目时间重叠（2026.03–06），你同时做两个项目？
- 🟡💣 为什么想离开现在的公司/为什么投通用岗不投医疗 IT？
  - 【加分点：济宁医学院计算机专业 → 医疗软件公司 → 医学项目，背景天然自洽，讲动机时用得上】
- 🟡 项目里遇到最难的问题？（✅ 从 §7/§8/§13 踩坑实录选 1 个背熟）
- 🔴 这些医学名词我不熟——PACS/RIS/DICOM 是什么？用外行话讲讲系统解决什么问题。

**三秒翻译表（黑话 → 通用语言，通用岗面试官的第一道坎）**

| 简历词 | 外行翻译 |

## 1. 整体架构与技术选型

- 🔴 为什么拆成两个服务？合并成一个行不行？
  - ↳ 两个系统怎么联动？（报告含 StudyInstanceUID → 查 pacs_db.study 置 has_image）
  - ↳ 联动为什么是 RIS 直查 PACS 的库，不是走接口？（⚠️ 备取舍：跨服务 DB 耦合 vs 接口调用的复杂度）
  - ↳ 两个库共用一个 MySQL 实例，业务上怎么隔离？
- 🔴 为什么 PACS 用 workflow/wfrest，RIS 用 muduo？
  - ↳ 两个库的线程/调度模型分别讲一下？（workflow：线程池+任务调度+协程式写法；muduo：one loop per thread）
  - ↳ 为什么不统一用一个库？
  - ↳ 为什么不用 brpc/drogon/oatpp/asio？（备 1–2 句对比）
  - ↳ 为什么用 C++ 写 HTTP 服务而不是 Java/Go？
  - 💣↳ 这些选型是你定的吗？【口径：团队既有技术栈，我参与调研 + 负责归档链路落地】
- 🔴 PACS 用 HTTP、RIS 用自定义 TCP 协议，为什么不对称？（✅§11：内网长连接高频短请求，二进制头 6B vs HTTP 头几百字节）
- 🟡 白板画整体架构图（含全部中间件和数据流向）。
- 🟡 系统的单点在哪？各组件挂了分别什么表现、怎么恢复？
  - RIS 挂 → 桥接 502 + 连接池自动恢复（✅§13）；Redis 挂 → 降级直查（✅§12）；MySQL 挂 → 接口失败+连接池自愈（✅§4）；Consul 挂 → 三级回落（✅§9）；RabbitMQ 挂 → 消息表堆积+补偿扫描（✅§8）
- 📐 系统吞吐多少？导入接口 QPS？检索 QPS？压测过吗？（⚠️ 压测未做，见附 B）
- 🟡 流量涨 10 倍，你先扩哪里？为什么？

## 4. 异步备份链：消息可靠性（重灾区，✅§8 大部分有答案）

- 🔴 Publisher Confirm 机制讲一下。
  - ↳ confirm 和 RabbitMQ 事务的区别？性能差多少？
  - ↳ 收到 nack 怎么办？路由不到队列怎么办？mandatory 标志？

- 🔴 手动 ACK 在什么时机发？auto ack 有什么问题？

  - ↳ 重试 5 次之后消息去哪？DLQ 里的消息怎么处理？
